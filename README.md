# Simulation Samples

Storage for the sample simulation files used on my [portfolio page](https://muzaffer-karakus.netlify.app). Main repository for the portfolio page is private

## Usage

Each simulation page has a folder here that matches its URL path (e.g. `#/4/1/2` → `4-1-2`). Download the process arguments file from that folder, then import it in the simulation to load the sample.
